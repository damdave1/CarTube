Search setup

Search uses YouTube's official API, which needs a free API key from your own Google account. Playing a pasted video link works without one.

  1. Open YouTube Data API v3 in Google Cloud, create a project if asked, and choose Enable.
  2. Under Credentials, choose Create credentials, then API key.
  3. Restrict the key. Application restrictions: Websites, and add . API restrictions: YouTube Data API v3.
  4. Type or paste the key here and save. To fix a typo, change that character in the box and save again.

CAPITALS white, small letters orange, digits blue, dash and underscore pink.

The key is stored only in this browser. The free quota allows about 100 searches a day.
